# Jenkins Calculator

A Java-based calculator application built to demonstrate continuous integration and build automation using Jenkins.

## Features
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division).
- Unit tests written with JUnit to verify calculations.
- Integrated `Jenkinsfile` for automated build and test pipelines.

## Tech Stack
- **Language:** Java
- **Build Tool:** Maven
- **Testing Framework:** JUnit
- **CI/CD:** Jenkins

## Getting Started

### Prerequisites
- Java Development Kit (JDK 11 or higher)
- Apache Maven
- Git
